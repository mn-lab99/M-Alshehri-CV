# M-Alshehri-CV

السيرة الذاتية الإعلامية لمحمد ناصر الشهري، موقع ثابت يعمل على GitHub Pages.

## الملفات
- `index.html` : الموقع كاملًا (التصميم والكود).
- `content.json` : كل النصوص وترتيب الصور والفيديوهات والشعارات والإعدادات.
- `media/` : الصور والفيديوهات والشعارات.

## كيف أعدّل المحتوى
**من الموقع نفسه**
1. افتح الموقع واضغط «الإدارة» ثم أدخل الرمز.
2. عدّل النصوص والصور والشعارات والترتيب والخط والألوان.
3. اضغط «تصدير للنشر»، فينزل `content.json` (أو `cv-update.zip` إذا رفعت ملفات جديدة).
4. ارفع الملف على المستودع (Add file ثم Upload files)، واستبدل `content.json`. وإذا كان zip فك ضغطه وارفع محتواه مع مجلد `media`.
5. بعد دقيقة تقريبًا يتحدّث الموقع للجميع.

**من Claude**
اطلب منه التعديل على `content.json` أو `index.html` في المستودع، وسيرفع التحديث.

> رمز الإدارة يفتح وضع التعديل في متصفحك فقط. النشر الفعلي يحتاج صلاحية الرفع على المستودع.
